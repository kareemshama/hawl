# Hawl

Local-first desktop Zakat calculator for Windows and macOS. Imports bank statements, tracks the hawl on the Hijri calendar, and shows a line-by-line audit trail with fiqh citations.

Status: M1 done, the rules engine in `packages/zakat-engine` passes 79 tests, one or more per rule. Next is M2, the desktop shell. See [docs/SPEC.md](docs/SPEC.md) and [docs/RULES.md](docs/RULES.md).
